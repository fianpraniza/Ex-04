# Benchmark Protocol

1. State model/version, device, OS, runtime, input size, workload, and repeat count.
2. Separate end-to-end stages from model-only latency.
3. Capture quality, size, P50/P95 latency, memory, throughput, and energy when available.
4. Use N/A with an explanation rather than fabricated values.
5. Preserve raw measurements or profiler captures and compare against a baseline.
