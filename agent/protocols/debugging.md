# Debugging Protocol

1. Restate the observed problem and expected behavior.
2. Capture a minimal reproducible baseline with environment, input, logs, and artifact versions.
3. Form a falsifiable hypothesis.
4. Change one meaningful variable at a time.
5. Measure the result and preserve evidence.
6. Record solution, trade-off, limitation, and prevention test.
7. Link the investigation, benchmark, evidence, and reflection to the ticket.
