# Ticket Completion Protocol

1. Confirm every acceptance criterion is objectively met.
2. Link code, commits, experiment, benchmark, evidence, decision, and reflection artifacts.
3. State remaining limitations and N/A rationale.
4. Move the Project item to REVIEW.
5. Review evidence against the issue.
6. Move to DONE only when completion is defensible.
7. Update current context and identify the next ready ticket.
