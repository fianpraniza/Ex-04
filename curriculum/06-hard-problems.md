# M6 - Hard Problems

## Objective

Solve realistic deployment and conversion failures using structured investigation.

## Why This Milestone Exists

Production work is defined by resolving non-happy-path behavior, not only completing tutorials.

## Competencies

L1 classify failure modes; L2 reproduce a failure; L3 investigate root cause; L4 benchmark mitigations; L5 document safe limitations and trade-offs.

## Concepts

Oversized models, failed conversion, unsupported operators, accuracy degradation, slow inference, memory pressure, hardware anomalies.

## Required Projects

Build a troubleshooting casebook from shrimp-detection deployment failures.

## Required Experiments

For each chosen challenge, record baseline, hypothesis, investigation, mitigation, benchmark, and limitation.

## Required Evidence

Minimal reproductions, logs, experiments, benchmarks, decision records, and casebook entries.

## Expected Outputs

A reusable evidence-based hard-problem investigation portfolio.

## Dependencies

M5 physical-device pipeline.

## Definition of Done

At least two non-happy-path problems follow Problem to Limitation and include reproducible evidence and measured mitigations.
